HPPV 內部測試版（Windows）
==========================

給測試同事（不需安裝 Python / Cursor）
--------------------------------------
1. 取得 `HPPV` 資料夾（內含 `HPPV.exe`）。
2. 將資料夾解壓到可寫入的位置（建議：桌面、文件資料夾）。
3. 雙擊 `HPPV.exe` 開始測試。

注意事項
--------
- 首次開啟可能較慢（會初始化資料庫與畫面）。
- 程式抓取馬會資料需可連外網。
- 若防毒軟體攔截，請將 `HPPV.exe` 與整個資料夾加到白名單。
- 請保留 `data` 資料夾，內含測試資料庫（若有提供）。

建議回報格式
------------
請提供以下資訊，方便開發者重現問題：
- 版本：例如 v0.1-test3
- 操作步驟：你做了什麼
- 預期結果：你期望看到什麼
- 實際結果：實際發生了什麼
- 截圖：錯誤畫面或異常畫面

給開發者：如何產生測試版
------------------------
1. 在專案根目錄執行：
   scripts\build_windows.bat
2. 打包輸出在：
   dist\HPPV
3. 把整個 `dist\HPPV` 資料夾交給測試同事。
